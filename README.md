# 🎯 Kiro Steering Templates (ES)

Bienvenido a la colección comunitaria de **Steering Templates para Kiro** (el IDE impulsado por IA de AWS). 

La función de *Steering* en Kiro nos permite darle contexto, reglas y buenas prácticas a la IA antes de que empiece a escribir código. Este repositorio proporciona plantillas listas para usar en diferentes entornos de desarrollo, traducidas y adaptadas para la comunidad hispanohablante.

## 🚀 Plantillas Disponibles

*   🐳 `devops-infra-steering.md`: Reglas para Docker, CI/CD e Infraestructura.
*   ⚛️ `react-ts-steering.md`: Reglas estrictas para frontend con React y TypeScript.
*   🐍 `python-api-steering.md`: Reglas para crear APIs robustas en Python.

## 🛠️ ¿Cómo usarlas?
Copia el contenido del archivo `.md` que necesites y pégalo en la configuración de Steering de tu entorno en Kiro. Esto asegurará que el código generado siga los estándares de tu equipo desde el primer momento.
